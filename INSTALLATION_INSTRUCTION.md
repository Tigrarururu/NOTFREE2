# Инструкция по установке мода Hidden Money Mod

## Структура файлов мода

```
hidden-money-mod/
├── src/
│   └── main/
│       ├── java/
│       │   └── com/
│       │       └── hiddenmoney/
│       │           └── mod/
│       │               ├── HiddenMoneyMod.java          # Основной класс мода
│       │               ├── HiddenMoneyModClient.java    # Клиентская логика и события
│       │               ├── EventSystem.java             # Система событий
│       │               └── mixin/
│       │                   ├── ClientPlayerEntityMixin.java     # Миксин для игрока
│       │                   ├── LivingEntityMixin.java           # Миксин для существ
│       │                   ├── ChatInputSuggestorMixin.java     # Миксин для чата
│       │                   └── KeyboardMixin.java               # Миксин для клавиатуры
│       └── resources/
│           ├── fabric.mod.json                  # Конфигурация Fabric
│           ├── hiddenmoney.mixins.json          # Конфигурация миксинов
│           └── assets/
│               └── hiddenmoney/
│                   ├── icon.png                 # Иконка мода
│                   └── lang/
│                       └── en_us.lang           # Локализация
├── build.gradle                     # Сборка Gradle
├── gradle.properties                # Свойства Gradle
└── settings.gradle                  # Настройки проекта
```

## Требования

1. **Minecraft версия:** 1.20.4
2. **Fabric Loader:** 0.15.7 или выше
3. **Fabric API:** 0.96.0+1.20.4
4. **Java:** 17 или выше

## Установка

### Шаг 1: Установка Fabric Loader

1. Скачайте установщик Fabric Loader с официального сайта: https://fabricmc.net/use/installer/
2. Запустите установщик
3. Выберите версию Minecraft 1.20.4
4. Нажмите "Install"

### Шаг 2: Установка Fabric API

1. Скачайте Fabric API версии 0.96.0+1.20.4 с CurseForge или Modrinth
2. Поместите файл `fabric-api-0.96.0+1.20.4.jar` в папку `mods`

### Шаг 3: Установка мода

1. Соберите мод командой: `./gradlew build` (если у вас есть исходный код)
2. Найдите собранный файл в папке `build/libs/hidden-money-mod-1.0.0.jar`
3. Поместите файл `hidden-money-mod-1.0.0.jar` в папку `mods`

Путь к папке mods:
- **Windows:** `%appdata%\.minecraft\mods`
- **Linux:** `~/.minecraft/mods`
- **macOS:** `~/Library/Application Support/minecraft/mods`

### Шаг 4: Запуск игры

1. Запустите Minecraft через лаунчер Fabric
2. Создайте новый одиночный мир или загрузите существующий
3. Мод активируется автоматически при загрузке мира

## Как проверить работу мода

После загрузки мира вы увидите панель справа вверху экрана с надписью "Баланс: 1000 ₽".

## Механики мода

### Начальный баланс
- При первом заходе в мир игроку выдаётся **1000 рублей**

### Расходы (автоматически)
| Действие | Стоимость |
|----------|-----------|
| Пройденный блок | -1 ₽ |
| Сломанный блок | -50 ₽ |
| Удар по чему угодно | -10 ₽ |
| Смена горячего слота | -5 ₽ |
| Прыжок | -20 ₽ |
| Нажатие Ctrl | -100 ₽ |
| Смерть | -500 ₽ |
| Получение урона | -150 ₽ |
| Открытие инвентаря | -15 ₽ |

### Доходы (автоматически)
| Действие | Награда |
|----------|---------|
| Выброс предмета | +1 ₽ |
| Установка блока | +2 ₽ |
| Переход из обычного мира в ад | +10 ₽ |
| Переход из ада в обычный мир | +5 ₽ |
| Убийство существа | +5 ₽ |
| Сообщение в чат (только 5 раз) | +50 ₽ |

### События (каждые 5 минут с шансом 50% при отрицательном балансе)

#### Баланс от -1 до -100:
1. Динамит под игроком (таймер 5 секунд, без урона)
2. Телепортация на 3 блока вверх
3. 5 зомби с именем "Буржуи"

#### Баланс от -101 до -500:
1. Динамит под игроком (таймер 3 секунды, без урона)
2. 10 зомби с именем "Буржуи"

#### Баланс от -501 до -1000:
1. 20 маленьких зомби с именем "Буржуи"
2. Эффекты (отравление, замедление, слепота, утомление, слабость) на 500 секунд + удаление предмета из руки

#### Баланс от -1001 и ниже:
1. Вардены с именем "Буржуи" в радиусе 10 блоков
2. Телепортация на 100 блоков вверх + эффекты на 500 секунд + удаление предмета из руки + снятие всей брони

## Важные примечания

1. **Мод полностью скрыт** - в чате и описаниях нет никакой информации о моде
2. **Единственный видимый элемент** - панель с балансом справа вверху
3. **Все механики работают автономно** - не требуется никаких команд или настроек
4. **Сообщения в чат дают награду только 5 раз** - после этого перестают приносить доход

## Сборка мода из исходного кода

Если вы хотите собрать мод самостоятельно:

```bash
cd /path/to/workspace
./gradlew build
```

Собранный файл будет находиться в: `build/libs/hidden-money-mod-1.0.0.jar`

## Устранение неполадок

### Мод не загружается
1. Убедитесь, что установлены Fabric Loader и Fabric API
2. Проверьте версию Minecraft (должна быть 1.20.4)
3. Проверьте логи игры на наличие ошибок

### Панель с балансом не отображается
1. Убедитесь, что вы играете в одиночном мире
2. Проверьте, что мод загружен (меню модов в главном меню)

### События не происходят
1. Убедитесь, что баланс отрицательный
2. Подождите 5 минут игрового времени
3. События происходят с шансом 50%
